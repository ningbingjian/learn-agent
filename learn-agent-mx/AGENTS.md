# 项目规范

- 中文沟通和文档，结论先行，简洁清楚；标识符、命令和路径保留原样。
- 已授权任务持续完成；要求先分析时，确认后再改。关键歧义、未授权的破坏性操作先询问，不重复索要授权。
- 先读代码，遵循约定，保留用户修改，不猜测结构或命令，不做无关重构或添加无关依赖。
- 代码简洁优雅，禁用 if...else、else if；允许独立 if 提前返回，禁用嵌套三元规避。
- 依据文件和工具结果，不编造、不泄密。
- 遵守上级指令；用户要求优先于技能建议。规则导致暂停时，指出文件、条款及原因。
- 仅按用户要求启用子代理，明确分工，由主代理整合验证。
- 测试与改动相称；不为可逆、低影响改动编写复述实现的测试。必要检查通过后，仅因新改动、失败或疑点扩大或重复验证。
- 简报关键进展；交付说明改动、验证及遗留问题（含失败、未验证项），不虚报完成；清理本次产生且无用的临时文件。
